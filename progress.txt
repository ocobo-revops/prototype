## Codebase Patterns
<!--
Reusable patterns discovered during implementation.
Add new patterns here as you learn them.

- Use pnpm, not npm
- Use ThemeColor type from types.ts for colour variants
- Container narrow prop for max-w-5xl, default is max-w-7xl
- Section bg prop accepts: white, gray, dark, yellow, sky, mint, coral
- SectionHeader exists in components/organisms/ - use for headers
- Existing atoms: Button, Badge, Input
- Existing molecules: Card, TestimonialCard
- Existing layout: Grid, FlexPair, HeroSplit, FeatureCard, ModularStackGrid
- Export new components from index.ts barrel files
