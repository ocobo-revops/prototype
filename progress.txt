## Codebase Patterns
<!--
Reusable patterns discovered during implementation.
Add new patterns here as you learn them.
Read this section FIRST on each iteration.
-->
- Use pnpm, not npm
- Tailwind config is TypeScript (tailwind.config.ts)
- Color tokens use ocobo- prefix
- ThemeColor enum in types.ts (YELLOW, MINT, SKY, CORAL, DARK)
- SVG illustrations are out of scope (decorative)
