## Codebase Patterns
<!--
Reusable patterns discovered during implementation.
Add new patterns here as you learn them.

-->

- Use pnpm, not npm
- Compound components: Grid.Cols, FlexPair.Icon, HeroSplit.Content pattern
- Layout components in components/layout/
- Illustrations in components/illustrations/
- CSS inheritance: font-size, text-color on parent section, not children
- Single tracking value: tracking-[0.3em] for all badges
- Tailwind @layer components in index.css
