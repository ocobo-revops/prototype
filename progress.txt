## Codebase Patterns
<!--
Reusable patterns discovered during implementation.
Add new patterns here as you learn them.

-->

- Use pnpm, not npm
- Do not git commit or push; ask before git add
- Prefer existing files over creating new ones
- Tailwind v4 config in tailwind.config.ts, PostCSS via @tailwindcss/postcss
- CSS entry point: src/styles/globals.css (imported in index.tsx)
- Fonts loaded from production domain: ocobo.co/fonts/
- ThemeColor enum exists in types.ts (YELLOW, MINT, SKY, CORAL, DARK)
- Button.tsx is the reference pattern for component structure
