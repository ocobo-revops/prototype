## Codebase Patterns
<!--
Reusable patterns discovered during implementation.
Add new patterns here as you learn them.

-->

- Use pnpm, not npm
- Biome for linting, not ESLint
- React 19 + Vite 6 + TypeScript
- No barrel files (index.ts re-exports)
- Named exports only, no default exports
- Kebab-case filenames
- Storybook 10 with a11y addon available
- Panda CSS config exports named `config` (not default)
- Run `pnpm panda codegen` after config changes
- styled-system/ alias configured in vite.config.ts
